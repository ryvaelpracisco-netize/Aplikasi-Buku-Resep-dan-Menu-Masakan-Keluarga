
# Aplikasi Buku Resep dan Masakan Keluarga

## Deskripsi
Aplikasi Buku Resep dan Masakan Keluarga merupakan
aplikasi berbasis web untuk menyimpan dan melihat
berbagai resep masakan keluarga.

## Tujuan
- Memudahkan pencarian resep masakan.
- Menyimpan bahan-bahan masakan.
- Menampilkan langkah-langkah memasak.
- Memudahkan penambahan dan penghapusan resep.

## Fitur
1. Menampilkan daftar resep.
2. Mencari resep berdasarkan nama.
3. Menambahkan resep baru.
4. Menghapus resep.
5. Menyimpan data menggunakan localStorage.

## Teknologi
- HTML
- CSS
- JavaScript
- Visual Studio Code
- Git dan GitHub

## Struktur Folder
aplikasi-buku-resep-keluarga/
- index.html
- style.css
- script.js
- README.md
- images/

## Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Buka file index.html menggunakan browser.
3. Cari resep melalui kolom pencarian.
4. Tambahkan resep melalui formulir.
5. Resep yang ditambahkan tersimpan di browser.

## Penyimpanan Data
Aplikasi menggunakan localStorage browser.
Data tersimpan pada browser dan perangkat yang sama.

## Pengembang
Nama: Isi nama anggota kelompok
NIM: Isi NIM anggota kelompok
Mata Kuliah: Isi nama mata kuliah
